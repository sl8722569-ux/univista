Early Access is a web app / PWA. Install it on Windows, Linux, macOS, Android, and iPhone from the browser (Install app / Add to Home Screen). Native APK and desktop installers come later.

Open UniVista Early Access

  • Windows / PC: open the app, then Install in Edge or Chrome.
  • Android: Chrome → Add to Home Screen.
  • iPhone: Safari → Share → Add to Home Screen.
  • Android TV / Google TV: planned for Beta.
