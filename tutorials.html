Tutorials

  1. Open Early Access (prefer localhost or this GitHub Pages URL so the camera works).
  2. Privacy → allow camera (and snapshots if you want stills).
  3. Live view → Start camera. Browser permission prompt is expected.
  4. Snapshot or Record clip. Files stay on this device.
  5. Watch motion to try tiny-object filtering. Or Simulate human event.
  6. Ask Mira: “open live view”, “what is Kira?”, “privacy”.
  7. Optional: Install / Add to Home Screen for Ziva-style fast launch.
