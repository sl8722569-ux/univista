# UniVista development workflow

1. Developer / Coda / Grok creates code.
2. Code is tested.
3. Code is committed to this Git repository.
4. Repository is pushed to GitHub.
5. Changes are reviewed. A pull request can be created.
6. **Human approval happens before production deployment.**
7. Then the approved version is deployed.

AI should not receive unrestricted production access. Do not put account passwords or API keys in plaintext.

Simulation cameras and “Simulate human event” exist so tests can run without a physical NVR.
