# UniVista — INSAN CREATIONS

Universal camera, AI, security & automation platform.

**Brand:** UniVista (not renamed because univista.com is taken).  
**Early Access** (The UniVista Book v1.2, Chapter 75): webcam/live view, recording, human-first motion filter, Mira, dashboard, local storage, basic alerts.

Principle: *Your camera doesn't have to become a UniVista camera. UniVista should learn how to work with your camera.*

## Run locally

Double-click `Open-UniVista.bat` or:

```
cd web
python -m http.server 8755
```

Then open http://127.0.0.1:8755/

Public site: https://sl8722569-ux.github.io/univista/  
App: https://sl8722569-ux.github.io/univista/web/

Install as an app: browser → Add to Home Screen / Install.
