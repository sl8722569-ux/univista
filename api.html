API / plugin documentation

Adapters translate manufacturer systems (ONVIF, RTSP, Xiaomi, V380, Arlo, others) into UniVista’s common interface. Plugin and HTTP APIs are not public in Early Access.

Planned adapter contract (draft):

  • discover() — Novi
  • connect() / reconnect()
  • liveView(), record(), ptz() where supported
  • compatibility() → fully | partial | unsupported + limitation text

Keys must never be logged in plaintext. AI must not hold unrestricted production credentials.
